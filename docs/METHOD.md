# 方法与执行分工

## A. 工程图证据推理

B008–B010 将受限的图像图元转为投影和特征证据。经人工确认后，FeatureGraph 表达特征候选、依赖及其来源，ModelingPlan 将确认的关系落到受支持的工序。R007 对结构化三视图中的尺寸、几何和材料侧约束求解，保留冲突或歧义，并通过重投影核对三维候选。

公开的 [R007 轮廓几何](../src/r007_geometry.py) 处理平面 LINE/ARC 轮廓的边界、接触及材料侧判定。[重投影模块](../src/r007_reprojection.py) 从三维候选生成 FRONT、TOP、LEFT，随后用独立步骤比较来源视图。图元位置与可见性各有结论。可见性证明限定于一个矩形宿主及互不相交、严格内置并贯穿整个宿主厚度的 Z 向圆柱 Cut。

R008 把缺失尺寸作为 UNKNOWN。待用户补充时，记录该参数的来源、适用约束和绑定情况，再形成条件计划。UNKNOWN 绑定已有离线记录，原案例中尚未确定的工程尺寸仍保留未定状态。

## B. 原生对象身份验证

项目使用 `GetPersistReference3` 采集持久引用，按当前文档用 `GetObjectByPersistReference3` 回解。对面核对所属 Feature，对草图核对其支撑面和坐标框架。对模型副本或保存重开后的文件重新解析对象，并检查引用状态、对象类型和相关关系。

[公开的 R008 坐标模块](../src/r008_frames.py) 表达受审的右手正交坐标系。执行时项目另从 SolidWorks 实测局部坐标变换，核对原点和方向。名称、距离和几何签名可帮助定位候选。进入编辑或确认身份需要当前文档的原生回读。

## C. 源图约束下的局部纠错

1. 记录源图依据、人工确认的修正意图、目标特征及允许受影响的下游范围。
2. 在副本上回解目标原生对象，核对待修改参数的原值和相关依赖，再更新已有特征或草图。
3. 保存、关闭、重开，复查参数、对象归属、下游的定义和几何，并生成引用修正零件的原生工程图。
4. 对比同一来源和物理视向下的图元，记录消除、保留、可见性改变及新增的差异。局部结果、文件往返、整图结果和工程验收分别记录。

## 执行与证据

常规建模和基础出图由上游 Automation 及 Engineering Drawing 执行。项目 R004 路径复用 R003 的按 PID 绑定与自有文档管理，R008 负责当前坐标与身份，R006 支持模型保存重开和几何观测。复杂件的专项工序仍由 Agent 根据当次图纸安排，通过按案脚本调用原版或项目的原生接口。

B 系列用于各契约的重建、验证和回归，F 系列试验针对特定原生操作及依赖，R 系列提供有界推理和原生支撑。六件协作交付与 B/F 的有界资格记录分别报告。 [历史结果](EXPERIMENTS.md)
